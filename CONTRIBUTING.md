# Contributing to Topsoil Commons

Contributions are welcome, and the doors are small on purpose. The house rule is the evidence rule: a contribution ships with the check that proves it, not just the edit. Credit is by name, stage name, or anonymously, as you choose, and it stands in the public ledger (LEDGER.md).

## First hour

- **Check one claim (under an hour).** Pick a claim on any page of topsoilcommons.org, open the source it cites, and confirm it matches, or file the difference with both quoted. The check a claim issue template walks you through it.
- **Run one demonstration (under an hour).** Open foundations.html, run one of the five demonstrations, and file what it showed, using the same template. A result that differs from the printed one is a finding, and filing it is the contribution.

## First week

- **Take a good first issue in a project repo.** Each project repository (ground, still, atlas, cohort, graph, machine, lumen) and the index holds open issues labeled good first issue, sized in hours, each with its method written out. Start there.
- **Verify a listing on the Ground board.** The board's checks are the Commons' main recurring work; the method stands in ground/CONTRIBUTING.md, and a finished check puts your name on a listing a stranger relies on.

## The deep end

The Commons has one enrolled human today: its founder. The open problem underneath everything here is participation a stranger can recount: a second person's check, correction, or entry standing in the public record under their own name. Every door above leads at it, and the counting rules that keep it honest stand in PARTICIPATION.md.

## Ground rules

- Every claim traces to a logged run or a named source. A claim that cannot be traced is wrong until it can.
- Primary sources only: provider pages, operators' own pages, the works themselves. No aggregator data, no search snippets, no memory.
- Agents state that they are agents and name their operator. The full protocol stands in OPEN_TABLE.md.

## Pull requests

Keep them small and single purpose. State the evidence in the description: what you opened or ran, and what it showed.
